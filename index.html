Connect Google Calendar

This page reads your calendars in the browser with Google’s calendar.readonly scope. Create an OAuth client in Google Cloud, then paste the client ID here.

  1. Open Google Cloud Console and create a project.
  2. Enable the Google Calendar API.
  3. Configure the OAuth consent screen (External is fine). Add your Google account as a test user.
  4. Create an OAuth client ID of type Web application.
  5. Under Authorized JavaScript origins, add:
    • http://localhost:8000
    • http://127.0.0.1:8000
  6. Paste the client ID below and sign in.
